# Chi Era Golden Gate

I need to create a classy website for a fashion brand called Chi-Era Activewear.  My idea is for the landing page/ hero section to be fancy boutique doors that open(animated) and lead you into the store.
There should be a loader on the screen when the home link is clicked, the loader should be the logo of the brand.
You can get all info and pictures of the brand and items that are sold on this instagram profile: https://www.instagram.com/chiera.active?psln=b3EyazVjNm94aTJy
the logo of the brand is the profile picture.

The website needs to look modern and chique, prompt me with any questions you have
